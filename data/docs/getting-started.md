# Getting Started with Meridian Cloud

Deploy your first app in under five minutes.

## Prerequisites

Install the CLI:

```
npm i -g meridian-cli
```

Then log in:

```
meridian login
```

## Deploy your app

From your project folder, run:

```
meridian deploy
```

Pick a region when prompted: `us-west`, `us-east`, or `eu-central`.
Meridian builds your project, provisions infrastructure, and prints a live URL.
